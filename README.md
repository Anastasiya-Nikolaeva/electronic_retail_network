# Django Project - Система управления сетью по продаже электроники

## Описание

Это веб-приложение представляет собой систему управления сетью по продаже электроники, 
разработанную с использованием Django и Django REST Framework. Приложение включает 
в себя API-интерфейс и админ-панель для управления поставщиками, продуктами и узлами сети.

Система организована в иерархическую структуру из трех уровней:

- **Завод** (уровень 0)
- **Розничная сеть** (уровень 1)
- **Индивидуальный предприниматель** (уровень 2)

Каждое звено сети ссылается на одного поставщика оборудования и содержит следующие элементы:

- Название
- Контактные данные:
  - Email
  - Страна
  - Город
  - Улица
  - Номер дома
- Продукты:
  - Название
  - Модель
  - Дата выхода на рынок
- Поставщик (предыдущий по иерархии)
- Задолженность перед поставщиком
- Время создания (автоматически заполняется)

В админ-панели отображаются созданные объекты, и на странице каждого узла сети доступны:

- Ссылка на «Поставщика»
- Фильтр по названию города
- Admin action для очистки задолженности перед поставщиком

### API

API предоставляет следующие возможности:

- CRUD операции для модели поставщика с запретом обновления поля «Задолженность перед поставщиком» через API.
- Фильтрация объектов по стране.
- Настройка прав доступа к API, чтобы только активные сотрудники имели доступ.

## Установка

1. **Клонируйте репозиторий:**
git clone <git@github.com:Anastasiya-Nikolaeva/electronic_retail_network.git>

2. Создание виртуального окружения
python -m venv venv
source venv/bin/activate  # Для Linux/Mac
venv\Scripts\activate  # Для Windows

3. Установка зависимостей
pip install -r requirements.txt

4. Настройка базы данных
Заполните файл .env.sample

5. Применение миграций
python manage.py migrate

6. Создание суперпользователя
python manage.py createsuperuser

7. Запуск сервера
python manage.py runserver

Теперь вы можете получить доступ к платформе по адресу http://127.0.0.1:8000/.

## Использование

API предоставляет следующие конечные точки:

Поставщики:
  - `GET /suppliers/` - Получить список всех поставщиков
  - `POST /suppliers/` - Создать нового поставщика
  - `GET /suppliers/{id}/` - Получить информацию о конкретном поставщике
  - `PUT /suppliers/{id}/` - Обновить информацию о поставщике
  - `DELETE /suppliers/{id}/` - Удалить поставщика

Продукты:
  - `GET /products/` - Получить список всех продуктов
  - `POST /products/` - Создать новый продукт
  - `GET /products/{id}/` - Получить информацию о конкретном продукте
  - `PUT /products/{id}/` - Обновить информацию о продукте
  - `DELETE /products/{id}/` - Удалить продукт

Узлы сети:
  - `GET /network-nodes/` - Получить список всех узлов сети
  - `POST /network-nodes/` - Создать новый узел сети
  - `GET /network-nodes/{id}/` - Получить информацию о конкретном узле сети
  - `PUT /network-nodes/{id}/` - Обновить информацию о узле сети
  - `DELETE /network-nodes/{id}/` - Удалить узел сети

Платежи:
  - `GET /payments/` - Получить список всех платежей
  - `POST /payments/` - Создать новый платеж
  - `GET /payments/{id}/` - Получить информацию о конкретном платеже
  - `PUT /payments/{id}/` - Обновить информацию о платеже
  - `DELETE /payments/{id}/` - Удалить платеж


## Тестирование

В проекте реализовано автоматизированное тестирование, которое охватывает основные функциональные возможности.

Команды запускающие тестирование:
- coverage run manage.py test electro.tests
- coverage run manage.py test users.tests

Просмотреть покрытие можно кодом:
- coverage report

### Процент покрытия тестами

тестирования, что обеспечивает высокую степень уверенности в корректности работы приложения.
